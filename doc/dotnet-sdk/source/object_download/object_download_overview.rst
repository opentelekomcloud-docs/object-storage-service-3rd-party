Object Download Overview
========================

OBS .NET SDK provides abundant APIs for downloading objects in the following modes:

-  :ref:`Performing a Streaming Download <obs_25_0502>`
-  :ref:`Performing a Partial Download <obs_25_0503>`
-  :ref:`Performing an Asynchronous Download <obs_25_0504>`
-  :ref:`Performing a Conditioned Download <obs_25_0506>`
-  :ref:`Performing a Resumable Download <obs_25_0510>`

You can call **ObsClient.GetObject** to download an object.
